# Torta de soya · Andipuerto

Visor académico de la Actividad 2, Grupo 2, ECOTEC. Fecha documental: 7 de noviembre de 2026; base estadística 2025.

## Contenido
Cadena interactiva, ficha de nueve campos, doce servicios, indicadores, simulación, controles de seguridad, discrepancias, informe y 21 fuentes.

## Procedencia
Adaptación de `Actividad2_Soya_Entrega.docx`, suministrado por el usuario. Se conserva el criterio SPTMF como fuente principal y las reservas del documento. Las referencias no fueron objeto de una nueva auditoría independiente al crear esta web. No representa una publicación oficial de ECOTEC, APG ni Andipuerto.

## Uso
Abrir `index.html` en un navegador. No requiere dependencias ni conexión para las interacciones. `data.json` contiene las tablas y referencias del documento base. El botón de impresión permite guardar un PDF desde el navegador.

## Simulación
Para una fracción r del rendimiento base, horas = horas_base / r y rendimiento = (carga / horas_base) × r. Promedios por escala únicamente para la base integral, con 119 arribos. Redondeo solo en pantalla. No calcula espera, demurrage, costos ni tiempos exclusivos de soya. Las horas agregadas no equivalen a ocupación calendario.

## Publicación
Carpeta independiente en el repositorio GitHub Pages existente. No modifica la portada ni otros proyectos.
